PostgreSQL
PostgreSQL (often called “Postgres”) is a free, open-source relational database management system (RDBMS) known for strong SQL standards compliance, extensibility, and reliability. Developed by the PostgreSQL Global Development Group, it powers everything from small web apps to large, mission-critical systems in finance, government, and tech.

Key facts
Type: Open-source object-relational database system (RDBMS/ORDBMS)

Initial release: 1996 (roots in POSTGRES project from 1986)

License: PostgreSQL License (permissive, GPL-compatible)

Primary language: C

Core strengths: Extensibility, ACID transactions, advanced SQL and JSON support

Background & history
PostgreSQL’s lineage starts with the POSTGRES research project at University of California, Berkeley in the mid-1980s, led by Michael Stonebraker as a successor to Ingres. In 1994, Postgres95 added SQL support; in 1996 it was renamed PostgreSQL to reflect its SQL capabilities and released as open-source. Since then, it has been continuously developed by a global community, becoming one of the most widely used open-source databases.

Core capabilities
PostgreSQL is an “object-relational” system: it supports traditional relational tables plus advanced types and extensibility. It offers full ACID transactions, multi-version concurrency control (MVCC) for high read concurrency, powerful indexing (B-tree, hash, GiST, GIN, BRIN, etc.), complex joins, window functions, common table expressions, and advanced query planning.

It supports both SQL and non-relational styles of work via JSON/JSONB, arrays, hstore (key-value), and rich full-text search, making it suitable for hybrid relational/document workloads.

Extensibility & ecosystem
A distinguishing feature is extensibility: users can define custom data types, operators, index methods, and functions in multiple languages (PL/pgSQL, Python, Perl, etc.). Foreign Data Wrappers let PostgreSQL query external data sources (other databases, files, services) as if they were tables. Many popular extensions exist, such as PostGIS for geospatial data and various analytics and compatibility layers.

Use cases & adoption
PostgreSQL is widely used as the primary data store or warehouse for web, mobile, analytics, and geospatial applications. Cloud providers such as Amazon Web Services (AWS), Microsoft Azure, and others offer managed PostgreSQL services, and notable users include large tech firms, mapping platforms, media organizations, and financial institutions.
