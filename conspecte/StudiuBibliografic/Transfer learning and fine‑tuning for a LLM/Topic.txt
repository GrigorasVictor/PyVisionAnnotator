Transfer learning în cazul modelelor de tip LLM presupune reutilizarea cunoștințelor învățate în etapa de pretraining și adaptarea acestora prin fine-tuning pentru task-uri specifice de procesare a limbajului natural.

Low-Rank Adaptation of Large Language Models (LoRA) is a 2021 research paper introducing an efficient fine-tuning technique for large pretrained language models. It reduces the number of trainable parameters by representing model updates as low-rank decompositions, dramatically cutting computation and storage costs without degrading performance.

Key facts
Authors: Edward J. Hu, Yelong Shen, Phillip Wallis, et al.

Published: 2021 (arXiv preprint: arXiv:2106.09685)

Main idea: Low-rank decomposition for parameter-efficient fine-tuning

Impact: Widely adopted for adapting large transformer models such as GPT and BERT

Open source: Implementation available via popular frameworks (e.g., Hugging Face PEFT)

Background and motivation
As transformer-based models like BERT and GPT scaled to billions of parameters, fine-tuning them for each downstream task became computationally expensive and memory-intensive. LoRA addresses this challenge by introducing a simple yet effective low-rank adaptation strategy, reducing the need to update full model weights.

Method and mechanism
LoRA freezes the original model parameters and injects trainable rank-decomposition matrices into specific layers (e.g., attention projections). Instead of updating full weight matrices, it learns two much smaller matrices whose product approximates the parameter updates. This low-rank update dramatically decreases the number of trainable parameters and GPU memory usage while maintaining model quality.

Results and impact
Experiments in the paper show that LoRA achieves performance comparable to full fine-tuning across several NLP benchmarks while training significantly fewer parameters. The method scales efficiently to large architectures, making it a cornerstone in parameter-efficient fine-tuning research. It has since been incorporated into many open-source LLM adaptation workflows, enabling cost-effective and modular deployment of customized models.
