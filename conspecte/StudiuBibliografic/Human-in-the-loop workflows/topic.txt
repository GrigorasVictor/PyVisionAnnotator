Human-in-the-Loop Workflows for Segmentation

Human-in-the-loop (HITL) segmentation systems combine automated segmentation models with human correction and verification. Instead of fully manual mask drawing, annotators iteratively refine machine-generated predictions, dramatically reducing annotation time while maintaining high-quality segmentation accuracy.

Modern HITL segmentation pipelines are central to:

medical imaging,
autonomous driving,
satellite imagery,
robotics,
and large-scale foundation-model annotation systems.









Polygon-RNN: Annotating Object Instances with a Polygon-RNN
Annotating Object Instances with a Polygon-RNN is a 2017 computer vision paper by Lluis Castrejon, Kaustav Kundu, Raquel Urtasun, and Sanja Fidler, presented at CVPR. It introduces Polygon-RNN, a model that predicts object instance masks as polygons in an interactive, human-in-the-loop way, targeting faster dataset annotation for instance segmentation. 

Key facts
Authors: Lluis Castrejon, Kaustav Kundu, Raquel Urtasun, Sanja Fidler 

Published: 2017 (preprint on arXiv; CVPR 2017) 

Core idea: Sequential polygon-vertex prediction with an RNN over CNN features 

Main dataset: Cityscapes instance segmentation 

Claimed speedup: ~4.7× average annotation speedup vs. manual, with human-level IoU agreement 

Problem and motivation
The paper addresses the high cost of annotating instance segmentation datasets, where precise object masks are typically drawn manually in polygon form. Traditional approaches treat segmentation as dense pixel labeling, but this does not match how annotators actually work, and it gives little leverage to speed up annotation time. Polygon-RNN reframes the problem: predict the polygon directly, so humans only correct mistakes instead of tracing every vertex. 

Model and method
Polygon-RNN takes a cropped object image (e.g., using a bounding box) and uses a CNN to extract features, followed by an RNN (specifically a GRU-type network) that autoregressively outputs polygon vertices one by one. At each time step, the RNN conditions on the image features and previous vertices to predict the next vertex location on a discretized grid. The sequence terminates when the model predicts a special end-of-sequence token, closing the polygon. 

The system is designed for interactive annotation: a human annotator can modify any predicted vertex during the sequence. Those corrections are then fed back into the RNN, which continues predicting the remaining vertices conditioned on the edited polygon, effectively combining model automation with human oversight.
