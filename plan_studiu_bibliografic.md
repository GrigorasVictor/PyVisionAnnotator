# Plan studiu bibliografic (7-8 pagini)

## 0) Cadru si reguli (0.5 pagini)
- Scop: prezentarea stadiului domeniului relevant pentru instrumente de adnotare vizuala.
- Precizeaza ca vei folosi citari IEEE si ca sumarizezi lucrari, fara copiere.
- Spune pe scurt cum sunt organizate sectiunile (teme + legatura cu proiectul tau).

## 1) Stadiul domeniului si tipuri de instrumente (1 pagina)
- Tema: state of the art in annotation tools (desktop vs web).
- Ce acoperi: tipuri de unelte, avantaje/dezavantaje, limitari uzuale.
- Legatura cu proiectul: justificarea unei aplicatii desktop semi-automate.
- Surse recomandate: folderul "A State-of-the-Art Review of Semantic Annotation Tools".

## 2) Modele de date si formate standard (1 pagina)
- Tema: modele de adnotare (bbox, polygon, mask) si formate (COCO, YOLO, VOC, CVAT JSON).
- Ce acoperi: ce reprezinta fiecare tip de adnotare, ce probleme rezolva, plus interoperabilitate.
- Legatura cu proiectul: suport multi-format, export consistent.
- Surse: "Annotation data models...", "Microsoft COCO...", "File formats and standards...".

## 3) Calitate si erori in adnotare (1 pagina)
- Tema: quality assurance, bias, erori, post-editare.
- Ce acoperi: acord inter-annotator, auditare, corectare masti, bias.
- Legatura cu proiectul: motivatia pentru verificare umana si UX orientat pe corectare rapida.
- Surse: "Quality assurance...", "Dataset bias...", "Error correction tools...".

## 4) AI asistat pentru adnotare (1-1.5 pagini)
- Tema: promptable segmentation, foundation models, zero-shot, pipelines det+seg.
- Ce acoperi: modele promptabile (punct/box/text), preantrenate, zero-shot.
- Legatura cu proiectul: AutoMask/AutoSeg, rolul omului in bucla.
- Surse: "Promptable Detection", "Zero-Shot Open-Vocabulary Segmentation", "Pretrained foundation models...", "Object detection + segmentation pipelines".

## 5) Colaborare in timp real si arhitecturi (1 pagina)
- Tema: colaborare multi-user, sincronizare, WebSocket/STOMP, securitate.
- Ce acoperi: sesiuni, evenimente, consistenta, autentificare/autorizare, privacy.
- Legatura cu proiectul: server separat, JWT, evenimente create/update/delete.
- Surse: "Collaborative annotation systems...", "Event-driven architectures...", "Security and privacy...", "Authentication and authorization...".

## 6) UX pentru eficienta (0.5-1 pagina)
- Tema: UI/UX patterns, overlays, zoom/pan, vizualizari ajutatoare.
- Ce acoperi: scurtaturi, ghidaje vizuale, opacitate masti, erori evitate prin confirmari.
- Legatura cu proiectul: crosshair, ajustari vizuale, confirmare la schimbare/iesire.
- Surse: "UI/UX patterns...", "Visual aid techniques...".

## 7) Concluzie de capitol (0.3-0.5 pagini)
- Sinteza punctelor cheie.
- Unde se pozitioneaza proiectul tau in peisaj.
